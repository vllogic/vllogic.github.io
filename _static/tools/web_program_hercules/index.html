🏭 Hercules Program 量产自动化 · 多片烧录 当前
🧰 准备工作
  • 将下载器的固件升级到 V00.57 或更高
  • 检查下载器指示灯：若 蓝灯 或 绿灯 亮起，请 双击模式键 切换，直至两灯均熄灭
  • 在 VLLINK CONSOLE 中，检查几项配置 Mode=wired 及 Vref_Voltage_mV=0
🚀 快速上手
  1. 点 Connect Vllink 连接下载器
  2. 文件表中添加固件并填烧录地址（默认 0x0）
  3. 选触发方式、状态输出动作与重试次数（默认2）
  4. 点 ▶ 开始量产，触发后自动烧录，结束点 ■ 停止
🔍 触发方式（6 种）
  • KEY Press：下载器的模式键按下
  • RXD ↑上升沿 / ↓下降沿：RXD 脚上的电平跳变
  • VREF ↑上升沿：掉电再上电（严格 0→1）
  • 手动触发：点 👉 手动触发 进行一次量产
  • 间隔触发：烧完一片后按设定间隔自动烧下一片（首次立即）
🚦 状态输出
  • 配置 TXD 脚 在烧录成功后的动作
  • 配置 SRST 脚 在烧录失败后的动作
  • 注意：TXD / SRST 两脚需 VREF 提供参考电平
🔒 烧写选项
  • Erase / Verify 量产强制开启
  • Auto Run：烧完自动复位
  • 重试次数：块级重试与整文件回退的上限（0-9）
📁 文件表要点
  • 烧写地址须 0x100 对齐，否则告警禁止开始
  • 多文件地址重叠 → 红色告警禁止开始
  • .acf + Cut ACF：自动裁剪文件头注释
  • 容量校验：烧写末端 ≤ 芯片容量
💾 配置与报表
  • 先通过「📁 授权目录」让网页获得固件目录访问权限
  • 首次配置完成后点「💾 导出配置」，保存全部配置
  • 后续使用：先「📁 授权目录」，再「📂 载入配置」即可恢复
  • 「📄 导出报表 CSV」= 统计 + 逐片明细 + 日志
⚠️ 环境：Chrome / Edge + HTTPS 或 localhost（WebUSB）。 统计：总烧录/成功/失败（不含重试）+ 含重试失败。
🏭 后台运行：烧写轮询为 USB 事件驱动，切到后台不受定时器节流影响； 运行中自动获取唤醒锁防止显示器/系统休眠。若顶部出现红色横幅， 说明浏览器正在节流，请将本标签页切回前台以获得最佳响应。
