🚀 快速上手
  1. 先按住设备上的按键，再连接电脑
  2. 点 Connect Vllink Device，在弹框中选择 "Vllink xxx Update" 再点击连接
  3. 点「选择文件」打开需要刷入的固件
  4. 点 Update，稍待片刻，固件更新完成

❗ 若未进入升级模式，弹框中将找不到 "Vllink xxx Update"，无法连接
