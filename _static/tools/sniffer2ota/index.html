写入固件

三种内置固件
  • 标准固件：正常分析仪功能，CH32H417 启动时载入 FPGA 位流。
  • FPGA 自由开发固件：CH32H417 不再载入或复位 FPGA，FPGA 相关 IO 释放为输入；仅 PB0 保留 25 MHz 时钟输出、PE14 保持高电平。可用外部 JTAG 自由开发，随时可以 OTA 回标准固件。
  • SWD 使能固件：上电后、正常启动前约 60 秒内 DP / DN 恢复为 SWD，可用 WCH-Link 擦除 CH32H417 并解除读保护。一旦擦除，分析仪功能永久失效，硬件不可逆退化为开发板。
升级说明
  • 仅使用 Chrome / Edge 等 Chromium 浏览器，并通过 HTTPS 或 localhost 打开。
  • 升级前请关闭 PulseView、sigrok-cli、Wireshark 等占用设备的程序。
  • 升级过程中请勿关闭页面或拔掉设备；复位后设备会短暂消失，这是正常现象。
  • 刷入 SWD 使能固件后，设备需要多等约 60 秒才会重新枚举。
设备没有重新出现？

先拔掉设备，等待 3 秒再插回，然后点击“重新连接”。刷过 SWD 使能固件时请至少等待 60 秒。

如果仍然没有设备：断电，将 PC2 拉低后上电，设备会停在 Slot A 的 IAP 服务；连接后重新刷入固件，再断电并松开 PC2。
